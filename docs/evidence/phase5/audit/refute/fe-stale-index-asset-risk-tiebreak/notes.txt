CLOUDFLARE DOCS (read 2026-10-20)
- workers/static-assets/headers: default "Cache-Control: public, max-age=0, must-revalidate", plus an ETag that is a hash of the file. The browser revalidates every time.
- workers/static-assets/routing/single-page-application: with no Worker script, an unmatched request gets /index.html with 200. With a Worker script, non-navigation requests that match no asset invoke the Worker. run_worker_first is available.
- workers/static-assets/routing/advanced/gradual-rollouts: version A's HTML can reference assets/index-<hash>.js, and that request can be routed to version B, "resulting in a 404 error and a broken page". The fix is version affinity.
- pages/configuration/serving-pages: same default Cache-Control and ETag. With no 404.html, Pages "serves the root (/) for any incoming path that does not correspond to a static asset".
