 Currently selected: Removal of operating system support with Node24 Removal of operating system support with Node24 What you need to do Editor’s note (August 25, 2026): Updated the Node20 removal date to September 23rd, 2026.
 Editor’s note (February 25, 2026): Updated the migration date to June of 2026.
 Editor’s note (May 19, 2026): Updated the migration date to June 16th, 2026.
 Node20 will reach end-of-life (EOL) in April of 2026.
 Beginning on June 16th, 2026, runners will begin using Node24 by default.
 This will only work until we upgrade the runner and remove Node20 on September 23rd, 2026.
 Node 24 does not have official support for ARM32, so self-hosted runners on ARM32 will no longer be supported after Node 20 deprecation.
